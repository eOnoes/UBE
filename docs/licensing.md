# UBE Licensing and Distribution Status

## Project license: MIT active

The owner-provided GitHub repository already contained an **MIT license with `Copyright (c) 2026 eOnoes`** in its initial commit. That root `LICENSE` is preserved unchanged, and every workspace package now declares `license.workspace = true` inheriting `MIT`. The earlier contributors-wording draft was not substituted for the owner's license; its resolution is recorded in `proposed-mit-license.md`.

MIT permits free private and commercial use, modification, redistribution, and sublicensing while preserving the copyright/license notice and warranty disclaimers. It does not replace third-party dependency, model, or font terms.

The team should still document ownership and contribution terms for future collaborators, decide whether original assets and branding need separate terms, consider trademark/name clearance, and obtain appropriate legal review before a public launch. This engineering preparation is not a legal-clearance opinion.

## Generated Windows third-party notices

`THIRD_PARTY_NOTICES.html` is the current bundle for nerd 0.1. It was generated with cargo-about 0.9.1 for `x86_64-pc-windows-msvc`, using `about.toml` and `tools/third_party_notices.hbs`.

Verified contents:

- **189 unique external dependency packages** in the Windows workspace report.
- **45 license-text groups**, all nonempty; multiple groups of the same license retain different package-specific copyright notices.
- No UBE workspace crates listed as third-party license grants.
- Cesium attribution/source links and the complete bundled IBM Plex Mono OFL text, checked against `assets/fonts/OFL.txt`.
- Structured verification data in `artifacts/ube-windows-notice-data.json`.

Strict generation with `--fail` passes after aligning UBE's MIT metadata. The accepted-license policy applies to external dependencies and chooses permissive alternatives where a package offers them. This automated result does not replace review of final distribution contents or non-code package assets.

Regenerate after dependency or target changes:

```powershell
cargo about generate --workspace --locked --fail --config about.toml tools/third_party_notices.hbs --output-file THIRD_PARTY_NOTICES.html
cargo about generate --workspace --locked --fail --config about.toml --format json --output-file artifacts/ube-windows-notice-data.json
```

Ship `THIRD_PARTY_NOTICES.html` with the applicable application and retain `assets/fonts/OFL.txt` and `assets/models/BoxTextured.SOURCE.md` in the distribution. Review source-availability and other obligations, including those for MPL-licensed components, before publishing.

## Original dependency inventory

`cargo metadata --format-version 1` was captured in `artifacts/ube-license-metadata.json`. At the nerd 0.1 checkpoint, the full resolved graph contained **352 external packages** and 11 workspace packages. Every external package declared a license expression; zero external packages had an undeclared `license` field.

Declared expressions include MIT, Apache-2.0, BSD variants, Zlib, ISC, MPL, Unicode, and expressions with optional GPL/LGPL alternatives. This graph includes inactive target/platform dependencies and is broader than the Windows notice report. The report above is the relevant current Windows bundle, not the earlier cross-target inventory.
